# Smart & Modern E-Commerce Platform

این پروژه یک پلتفرم فروشگاهی مدرن، پرسرعت و بهینه برای سئو است که بر پایه معماری فول‌استک Next.js طراحی شده است.

## پیش‌نیازها
- Node.js (نسخه 18 به بالا)
- PostgreSQL
- npm یا pnpm
