# EXTIM E-Commerce Platform

This project is a modern, high-performance, and SEO-optimized e-commerce platform built on a monolithic Next.js architecture.

## Prerequisites
- Node.js (version 18 or higher)
- PostgreSQL
- npm or pnpm
